# JNV Spectra - Event Management Website

A modern, responsive event management website built with React, TypeScript, and Tailwind CSS, designed to showcase event planning and rental services across Florida.

## Features

- Modern, responsive UI with shadcn-ui components
- TypeScript for type safety
- Tailwind CSS for styling
- Framer Motion animations
- React Query for efficient data fetching
- Comprehensive form handling with React Hook Form
- SEO optimized

## Prerequisites

- Node.js (v18 or higher)
- npm or bun package manager

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd jnv_spectra_website
```

2. Install dependencies:
```bash
npm install
# or if using bun
bun install
```

3. Start the development server:
```bash
npm run dev
# or
bun dev
```

## Building for Production

```bash
npm run build
# or
bun run build
```

To preview the production build:
```bash
npm run preview
# or
bun run preview
```

## Project Structure

```
src/
├── components/    # Reusable UI components
├── lib/          # Utility functions and configurations
├── pages/        # Page components
├── styles/       # Global styles and Tailwind configurations
└── types/        # TypeScript type definitions
```

## Tech Stack

- [Vite](https://vitejs.dev/) - Build tool and development server
- [React](https://reactjs.org/) - UI library
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [shadcn/ui](https://ui.shadcn.com/) - UI component library
- [Framer Motion](https://www.framer.com/motion/) - Animation library
- [React Query](https://tanstack.com/query/latest) - Data fetching and caching
- [React Hook Form](https://react-hook-form.com/) - Form handling
- [Zod](https://zod.dev/) - Schema validation
